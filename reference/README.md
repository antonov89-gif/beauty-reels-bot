# reference/

Third-party material vendored here for browsing/reference only — not
wired into the bot or the render pipeline, and not meant to be run
from this repo.

## awesome-llm-apps

Source: https://github.com/Shubhamsaboo/awesome-llm-apps (reviewed before
inclusion). 100+ example AI agent / RAG / voice-agent mini-projects.
Each subfolder is an independent example with its own dependencies and,
in most cases, its own API keys — nothing here has been installed or run.

Demo videos, GIFs, and git history were stripped before commit to avoid
bloating this repo (original ~230MB with .git; trimmed to ~46MB).
