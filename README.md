# beauty-reels-bot

Telegram-бот на aiogram для конвейера UGC-контента для бьюти-рилсов:
идеи → сценарий → рендер видео → (в перспективе) публикация в Instagram.

## Рендер видео

Реальный рендер подключён через **HyperFrames** (`VideoRenderAgent` в
`reels_mvp.py`): текст черновика (заголовок/хук/тело/CTA) подставляется в
шаблон `reels-video/templates/reel-card.template.html` и рендерится
`hyperframes` CLI в MP4.

Полноценных футажей нет (`visual_prompt`/`audio_prompt` — это ТЗ для
AI-видео/аудио-генерации, для которой в проекте пока не настроены
платные API), поэтому сейчас рендерится анимированная текстовая карточка
(hook → body → CTA), а не сгенерированное видео со сценой.

### Локальный запуск

Нужны: Python 3.10+, Node.js 22+, FFmpeg, Chrome/Chromium.

```bash
pip install -r requirements.txt
npm install -g hyperframes@0.8.68
hyperframes browser ensure
export TELEGRAM_BOT_TOKEN=...
python3 reels_mvp.py
```

### Продакшен (Docker)

`Dockerfile` в корне ставит Node.js + FFmpeg + HyperFrames + Python-зависимости
в один образ — без него на обычном Python-buildpack (например, стандартный
деплой на Render.com) рендер будет падать: FFmpeg/Chrome там не установлены.

```bash
docker build -t beauty-reels-bot .
docker run -e TELEGRAM_BOT_TOKEN=... -p 8080:8080 beauty-reels-bot
```

### Кнопка «Превью» и одобрение черновика

- **🎬 Превью (рендер)** — рендерит и присылает видео в чат, не меняя статус
  черновика.
- **✅ Одобрить** — рендерит, присылает готовое видео, затем передаёт в
  `InstagramPublishingAgent` (реальная публикация всё ещё требует
  `INSTAGRAM_ACCESS_TOKEN` и **публичного** URL видео — см. предупреждение
  в `publish_draft_to_instagram`, если токен настоящий, а `media_url`
  остался локальным путём).

## Известная проблема: битая кодировка кириллицы

Значительная часть кириллических строк в `reels_mvp.py` (логи, тексты кнопок,
сообщений) физически повреждена — это не проблема отображения, а реальная
порча данных в файле (текст один раз был неправильно перекодирован через
cp1251 до сохранения в UTF-8). Из-за этого бот показывает пользователям в
Telegram битый текст в части сообщений.

Новый код (`VideoRenderAgent`, `handle_preview`, обновлённый
`handle_approval`) использует корректную кириллицу. Остальной файл требует
отдельного прохода на исправление кодировки — это не сделано в рамках
подключения рендера, чтобы не рисковать массовой автозаменой без ручной
проверки на неоднородных участках файла.
