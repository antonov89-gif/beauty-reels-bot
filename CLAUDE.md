# Mr. Buck channel project: standing rules

- **MAIN GOAL (user, 22.10.2026): get the channel monetised (YouTube Partner Program), then TikTok monetisation.** Every decision is weighed against it: (1) reach the YPP thresholds (subscribers + watch hours or Shorts views; check the current numbers on YouTube Help before quoting them); (2) keep the channel clean for the YPP review: original value added (own graphics, research, commentary), no reused or mass-produced content, correct AI/altered-content disclosure, no unlicensed imagery or music (Esri-free imagery policy, own music), no misleading metadata, no strikes; (3) prefer formats and topics that raise views, watch time and subscribers; (4) report progress toward monetisation in the growth log. Do not trade this goal for short-term views.
- **Authenticity check is mandatory for every video** (user rule, 22.10.2026). Before any video is shown as final, uploaded, scheduled or published, run the `authenticity-check` skill (`.claude/skills/authenticity-check/SKILL.md`) on the final file, write the audit to `map_shorts/<project>/authenticity_audit_<date>.md`, and only then deliver. A re-render re-runs the affected checks. Anything not verified is reported as NOT VERIFIED, never as PASS.
- Ask before any paid generation and name the cost (the price can differ between providers: check the provider's price before quoting).
- Label AI visuals (on screen, in the description, platform flags); AI voice is disclosed too.
- Never print or commit keys. No PR unless asked. Do not commit videos.
- Reply to the user in Russian, briefly; video text and publication packages are in English.
- **Reference analysis rule (user, 25.10.2026): the visual analysis must be accurate.** Any "make it like this reference" request: (1) ask for the reference mp4 (YouTube blocks yt-dlp here); (2) run `map_shorts/prompts/frame_forensics.py <video> <out_dir> --dense 10` and write the second-by-second table from the real frames; vidIQ/Gemini text is only a hypothesis until confirmed on frames; without the file mark the visual analysis "NOT VERIFIED ON FRAMES"; (3) follow the replication protocol, PHASE 92-96 in `map_shorts/prompts/video_dna_analyzer_v2.md` (double watch, one-sentence "what surprises the viewer" test, reference/ours table shown BEFORE any generation or paid call, AI-clip checklist from a contact sheet before editing, not-a-copy check in the authenticity audit).
- **Self-check before showing (user, 26.10.2026): "проверяй всё сам, я не должен показывать твои ошибки".** Before any preview or final: measure and compare every element against the reference and the plan (music present and audible: bed level vs voice, BPM; captions; chips vs logs; burned-in text; cuts; loudness; last frame), write the result to `reference_check.md` / the audit, fix what fails, and only then show. Never send a file whose check you have not run.
- **Production gate (user, 26.10.2026; skill upgraded 28.10.2026):** for reference-based videos use the `youtube-cinematic-dna` skill (now V5.4.1 audited) together with video-dna-analyzer: evidence level per claim, acceptance gate per shot before generation, pilot of 2–3 shots before any batch, at most 2 corrective attempts per shot, statuses GENERATED ≠ INSPECTED ≠ APPROVED in reference_check.md. Mapping: `.claude/skills/youtube-cinematic-dna/PROJECT_INTEGRATION.md`.
- **YouTube link rule (user, 28.10.2026): "используй когда скидываю ссылку".** Every YouTube link the user sends (youtube.com, youtu.be, /shorts/) is handled with the `youtube-cinematic-dna` skill V5.4.1: a bare link = ONE_LINK_STUDIO (no question what to do), apply channel routing first, data from vidIQ/Nexlev, visual claims marked NOT VERIFIED ON FRAMES until the mp4 is sent, 3 original stories + recommended style + 20–40 s pilot plan, stop before any paid step.
- **Channel routing rule (user, 27.10.2026): references are routed by niche, styles are never mixed.** We run several channels, each with its own niche and its own memorable visual identity. The Mr. Buck channel is GEOGRAPHY only. When the user sends a reference that is NOT about geography (a story, history, science, a 3D film-style short), it is NOT for the geography channel and its look is NOT adopted by it. Analyse it for principles, route it to the matching other channel, and keep that channel's own style. The geography channel keeps its recognisable look (Esri-free satellite maps restyled in premium 3D, our banner, stamps, chips, captions with the yellow active word, own beat). Before any production, say which channel the video is for; if unclear, ask once. Registry and style bibles: `map_shorts/channels.md`. Publishing: only Mr. Buck (YouTube mr.buck000, TikTok mr.buck222) is connected to Zernio; another channel needs its own account connected first, never publish a non-geography video to Mr. Buck.
- **Fiction rule for the stories channel (user, 27.10.2026): "we do not have to take facts from reality, we create our own reality."** The stories channel (not Mr. Buck) may use ORIGINAL invented stories, characters, places and numbers. Limits that stay: (1) never present an invented event as true, as news or as "a true story"; the description says it is a fictional story; (2) no real person's name, likeness or brand, and no real tragedy retold with invented details as if real; use "inspired by" only when the core is accurate; (3) AI visuals/voice disclosed and platform flags ON; (4) no gore, no violence against children, nothing made for kids; (5) the authenticity audit for fiction checks these limits instead of facts (see `map_shorts/channels.md`). The geography channel stays fully fact-checked with sources.

Every video starts with the signature opener and ends with the outro, and the king says "what a handsome man I am" ONCE per video, in the opener (owner 29.10), no other direct praise of his looks (`map_shorts/history_channel/louis_series_bible.md`).
