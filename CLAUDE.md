# beauty-reels-bot

Telegram-бот (aiogram 3) — «оркестратор» UGC-контента для бьюти-Reels в Instagram.
Весь код в `reels_mvp.py`, зависимости в `requirements.txt`.

## База знаний (`kb/`) — память проекта между сессиями

Облачные сессии стираются, а `kb/` лежит в git — это долговременная память.

- `kb/raw/` — сырьё: черновые мысли, ссылки, разборы чужих рилсов, транскрипты. Пишет пользователь или Claude, без требований к форме.
- `kb/wiki/` — чистые структурированные страницы по темам. Ведёт Claude.
- `kb/output/` — готовые результаты: сценарии, контент-планы, отчёты.

### Правила

1. **В начале задачи** прочитай `kb/wiki/index.md` и страницы, относящиеся к задаче.
2. **Новые факты и решения** (о проекте, нише, что сработало / не сработало) — внеси в подходящую страницу `kb/wiki/` или создай новую и добавь ссылку в `kb/wiki/index.md`.
3. **Если в `kb/raw/` есть необработанные заметки** — перенеси суть в `kb/wiki/`, а сам файл из `raw/` не удаляй.
4. **Готовые артефакты** (сценарии, планы, отчёты) сохраняй в `kb/output/` с датой в имени: `YYYY-MM-DD-тема.md`.
5. Ссылки между страницами — в формате Obsidian: `[[имя-страницы]]`.
6. Пиши по-русски, коротко, фактами. Не дублируй — обновляй существующую страницу.
