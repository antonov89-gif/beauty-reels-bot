# YouTube Channel Lab

Цель: выпускать ролики, которые по форме не уступают лучшему каналу ниши, но со своим
содержанием, и с каждым роликом становиться точнее. **Знания живут в `kb/wiki/youtube/`
(в git), а не в этом файле.** Этот файл — порядок работы.

## Всегда, в начале
1. `kb/wiki/youtube/youtube-lab.md` — какие каналы ведём, образцы, активные эксперименты.
2. `kb/wiki/youtube/youtube-lessons.md` — правила с уровнем доверия. Правило `confirmed`
   важнее общего совета из `references/`. Правило `refuted` не применять.
3. Работа про конкретный канал → его библия `kb/wiki/youtube/channels/<канал>.md`.
4. Один раз за сессию перед модулями 1 и 3 — `references/00-rules.md` (границы копирования).

Новый канал: 1 → 2 → 3 …

## Модуль 6. Обучение — задача не закончена без него
- **Урок** → строка в `youtube-lessons.md`:
  `- [статус] правило — доказательство (ID роликов / цифры / источник, дата)`.
  Статусы: `hypothesis` (одно наблюдение или чужой канал), `confirmed` (подтверждено ≥2
  нашими роликами или явной метрикой), `refuted` (проверили — не работает).
  Похожее правило уже есть → обнови статус и доказательства, не дублируй.
- **Тренд** → `youtube-trends.md`: дата, тема, источник с цифрами, оценка, срок годности.
  Старше 30 дней для Shorts → пометить `stale`.
- **Опубликованный ролик** → строка в `youtube-experiments.md`: гипотеза, что меняли,
  метрики через 48 ч и 7 дней, вывод.
- **Ретро** раз в неделю или после 5 новых роликов: перечитай эксперименты, подними/опусти
  статусы уроков, слей дубли, удали устаревшее.
- **Запрещено:** выдумывать цифры; ставить `confirmed` без измерения; записывать в уроки
  то, что не проверял, как факт.

## Инструменты
| Задача | Чем | Ограничения |
|---|---|---|
| Метаданные, ролики канала, выбросы, транскрипты | Nexlev: `channel_resolver`, `youtube_channel_about`, `youtube_channel_shorts`, `youtube_channel_videos`, `youtube_channel_outliers`, `get_bulk_video_transcripts`, `youtube_video_details` | бесплатно 50 вызовов/неделю на все инструменты |
| Визуальный разбор ролика | Nexlev `watch_youtube_video_and_ask`; vidIQ `vidiq_watch_shortform_content`, `vidiq_video_watch`; Higgsfield `video_analysis_create` (покадрово, 3–5 мин) | кредиты; разбирать 2–3 ролика, не все |
| Тренды, выбросы, ключи | vidIQ `vidiq_outliers`, `vidiq_trending_videos`, `vidiq_keyword_research`; Nexlev `search_viral_videos_small_channels`, `faceless_outliers_videos`, `get_similar_channels` | кредиты vidIQ |
| Оценка заголовка/обложки | vidIQ `vidiq_score_title`, `vidiq_score_thumbnail`, `vidiq_similar_thumbnails` | кредиты |
| Производство видео | OpenMontage (`~/OpenMontage`, если установлен), скиллы `remotion:*`, `anthropic-skills:map-shorts-*`, Higgsfield/cellcog для ИИ-видео | ИИ-генерация платная |
| Пакет публикации | `anthropic-skills:shorts-publication-package`, `claude-youtube` (`/youtube seo`, `/youtube shorts`) | — |
| Публикация и аналитика | Zernio: `accounts_list`, `media_generate_upload_link`, `posts_create`, `analytics_get_analytics`, `analytics_get_post_timeline`, `analytics_get_best_time_to_post` | публикация — только после «да» пользователя |
| YouTube из контейнера напрямую | закрыт сетью | транскрипты — через Nexlev/vidIQ |

Нет нужного инструмента или кончились лимиты → скажи прямо и попроси у пользователя
скриншот/название/описание, не угадывай.

а выводы — в `kb/wiki/youtube/` через модуль 6.
