# 01. Разбор канала-образца → библия канала

Результат: `kb/wiki/youtube/channels/<канал>.md` по шаблону `templates/channel-bible.md`.
Каждое утверждение в библии — с примером (ID ролика). Без примера — не утверждение.

## Шаг 1. Выборка (дёшево, только метаданные)
1. Nexlev `channel_resolver` (ссылка/@хендл → ID) → `youtube_channel_about` (ниша, частота,
   подписчики).
2. `youtube_channel_shorts` или `youtube_channel_videos` — последние 30–50 роликов.
3. `youtube_channel_outliers` — что выстрелило **относительно медианы канала**.
4. Отобрать 10: **5 лучших + 3 средних + 2 худших.** Контраст лучших и худших объясняет,
   что работает, лучше, чем одни лучшие.

## Шаг 2. Текст (дёшево)
`get_bulk_video_transcripts` по 10 роликам. Для каждого записать:
- хук: первые 1–3 с дословно, тип (вопрос / противоречие / запрет / цифра / «вы не знали»);
- сколько фактов/шагов, где поворот, где самый сильный момент (в какой трети);
- концовка: петля к началу / CTA / вопрос / ничего;
- слов в минуту (темп), длительность.

## Шаг 3. Визуал (дорого — только 2–3 лучших ролика)
Nexlev `watch_youtube_video_and_ask`, vidIQ `vidiq_watch_shortform_content` или Higgsfield
`video_analysis_create`. Задать вопросы по чек-листу **одним запросом**:

**Кадр и материал**
- Ведущий в кадре или faceless? Что на экране: карты / стоки / ИИ-кадры / анимация /
  скринкаст / съёмка / смешанное?
- Средняя длина плана (с). Есть ли движение камеры (зум, панорама) на статичных кадрах?

**Текст на экране**
- Тип шрифта, толщина, цвет заливки и обводки, тень.
- Позиция (верх / центр / низ, примерно в % высоты), сколько слов за раз,
  подсветка активного слова (караоке)?
- Отдельные «удары» крупным текстом на цифрах/ключевых словах?

**Графика и эффекты**
- Стрелки, плашки, бейджи, эмодзи, счётчики, обводки объектов, сравнение размеров?
- Тряска, вспышки, хроматическая аберрация на склейках, переходы?
- Палитра: 3–5 основных цветов (hex, если можно определить), грейдинг (тёплый/холодный).

**Звук**
- Голос: живой / ИИ, пол, темп, эмоция, язык.
- Музыка: жанр, громкость относительно голоса, приглушается ли под речь.
- SFX: на каждое появление/удар (whoosh, pop, boom, tick)?

**Ритм**
- Как часто меняется что-то на экране (раз в N с)? Есть ли «мёртвые» паузы?

## Шаг 4. Упаковка
- Заголовки 10 роликов → формула(ы): «X vs Y», «Почему…», «N фактов…», цифра + интрига.
- Обложка/первый кадр: что крупно, сколько слов, цвета (`vidiq_similar_thumbnails`).
- Описание, хештеги, теги, частота и время публикаций.

## Шаг 5. Сборка библии
Заполнить шаблон. Отдельно раздел **«Отличие лучших от худших»** — 3–5 пунктов, это самая
ценная часть. Всё, что выведено из одного ролика, — помечать как гипотезу.

## Шаг 6. Обучение
Наблюдения, которые верны не только для этого канала (например, «у всех лучших хук-вопрос»),
→ `youtube-lessons.md` со статусом `hypothesis` и ссылкой на канал-образец.

## Экономия лимитов
Nexlev бесплатно — 50 вызовов в неделю на все инструменты. Порядок: метаданные → транскрипты
→ визуальный разбор только 2–3 роликов. Кончились лимиты → попросить у пользователя
скриншоты кадров и описание, разбирать по ним.
