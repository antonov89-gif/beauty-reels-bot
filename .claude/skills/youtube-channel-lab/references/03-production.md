# 03. Производство ролика в стиле образца

Вход: бриф (`templates/video-brief.md`) + библия канала. Выход: видео + `.srt` + запись
в `kb/output/YYYY-MM-DD-<тема>.md` (бриф, сценарий, источники фактов, настройки рендера).

## Шаг 1. Сценарий
- Хук ≤2 с: тип хука — тот, что у лучших роликов образца (см. библию).
- Что-то новое на экране каждые 1,5–3 с: факт, цифра, смена плана, удар текстом.
- Самый сильный факт — не в начале, а на 60–75% ролика (держит досмотр).
- Концовка — как у образца: петля к первой фразе / вопрос в комментарии / CTA.
- Длительность и темп (слов в минуту) — из библии, ±10%.
- Каждое предложение = одна строка с пометкой визуала: `[план] текст голоса`.

## Шаг 2. Проверка фактов (до озвучки)
Каждая цифра → источник (ссылка, дата) в файле из `kb/output/`. Не нашёл — убрать или
«примерно». См. `00-rules.md`.

## Шаг 3. Голос
| Вариант | Когда |
|---|---|
| Piper (OpenMontage, бесплатно) | черновик, RU/EN |
| Kokoro (`am_michael` и др.) | EN, бесплатно, стиль map-shorts |
| ElevenLabs / Higgsfield `generate_audio` | финал, нужен ключ/кредиты |
Темп и эмоция — по библии. Чужой голос не клонировать.

## Шаг 4. Визуал
| Стиль образца | Чем делать |
|---|---|
| Карты, страны, сравнения размеров | скиллы `anthropic-skills:map-shorts-pipeline`, `map-shorts-animation-engine`, `shorts-effects-dynamics`; `remotion:remotion-maps` |
| Моушн-графика, текст, инфографика | `remotion:*`, `ecc:remotion-video-creation`, `ecc:manim-video` |
| Стоки + голос + субтитры | OpenMontage (`~/OpenMontage`) |
| ИИ-кадры/видео | Higgsfield `generate_image` / `generate_video` (платно — спросить) |
| Скринкаст (обзоры инструментов) | Playwright-скриншоты + Remotion |

## Шаг 5. Монтаж и тех. требования
- 1080×1920, 30 fps, H.264, yuv420p, AAC 48 кГц.
- Громкость −14 LUFS, true peak −1,5 dBTP; музыка под голосом с приглушением (ducking).
- Безопасные зоны Shorts: текст не ниже ~80% высоты и не правее ~85% ширины
  (там кнопки и подпись).
- Субтитры вшиты + отдельный `.srt`.
- Проверка: `ffprobe` (размер, fps, длительность), `ffmpeg -af loudnorm=print_format=json`.

## Шаг 6. Контроль качества (перед показом пользователю)
- [ ] Хук ≤2 с, первый кадр сам по себе понятен без звука.
- [ ] Нет «мёртвых» отрезков >3 с без изменений на экране.
- [ ] Все факты из сценария есть в списке источников.
- [ ] Текст в безопасных зонах, читается на телефоне.
- [ ] Громкость и формат по требованиям выше.
- [ ] **Сравнение с образцом:** 3 кадра нашего ролика рядом с 3 кадрами образца
  (тот же момент: хук / середина / концовка) — шрифт, плотность, палитра, темп совпадают?
  Расхождения → исправить или записать как осознанное отличие.

Нашёл, что ускоряет или ломает производство → урок в `youtube-lessons.md`.
