# 04. Упаковка и публикация

Выход: пакет публикации в `kb/output/YYYY-MM-DD-<тема>-пакет.md`, публикация — только после
явного «да» пользователя.

## Заголовок
- ≤60 символов, главное слово в первых 40 (обрезка в ленте).
- 3 варианта по формулам из библии образца («X vs Y», «Почему…», цифра + интрига,
  «Вы не знали…»). Не кликбейт, который ролик не оправдывает: обман = свайп = минус охват.
- vidIQ `vidiq_score_title` для каждого варианта → берём лучший, остальные — в запас для
  перезаливки/A-B.

## Обложка / первый кадр
- Для Shorts первый кадр = обложка в ленте: крупный объект + ≤3 слова, контраст.
- Для длинных — `vidiq_score_thumbnail`, `vidiq_similar_thumbnails` (сравнить с нишей).

## Описание, хештеги, теги
- Первая строка описания = суть + ключевое слово. 2–3 хештега (`#shorts` + ниша).
- Скилл `anthropic-skills:shorts-publication-package` или `/youtube seo`, `/youtube shorts`.
- Реалистичный ИИ-видео/голос → отметка «изменённый или синтетический контент».

## Время
Zernio `analytics_get_best_time_to_post` (по нашему аккаунту). Данных мало → время из
библии образца. Записать выбранное время в эксперимент.

## Публикация через Zernio (только после «да»)
1. `accounts_list` → выбрать `account_id` нужного YouTube-канала (их несколько — не угадывать).
2. `media_generate_upload_link` → загрузить файл → `media_check_upload_status`.
3. `validate_post` → `posts_create` (с `account_id`, заголовок, описание, время).
4. Сразу строка в `youtube-experiments.md`: дата, канал, ID, гипотеза ролика.
