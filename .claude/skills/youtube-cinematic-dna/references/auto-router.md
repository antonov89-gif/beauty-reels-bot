# AUTO ROUTER V5.4

## Intent precedence
1. Existing verified project + `дальше` / `continue` → `CONTINUE`; use saved `NEXT_ACTION`.
2. A request to repair an identified actual generated clip → `REPAIR`.
3. Reference versus actual output → `COMPARE`.
4. Explicit budget/model cost comparison → `BUDGET`.
5. Explicit packaging/posting strategy → `PACKAGE` / `GROWTH`.
6. Explicit only analysis → `ANALYZE`.
7. Explicit story/idea-only → `IDEATE`.
8. Two or more distinct reference video URLs without narrower override → `MULTI_REF`.
9. Explicit create/film/replicate visual language with original story → `CREATE`.
10. **One bare YouTube URL or URL with no explicit task → `ONE_LINK_STUDIO`.**

`ONE_LINK_STUDIO` itself includes SCOUT, 3 original ideas, recommended concept, look, shots and connected pilot specification; it does not merely summarize the reference. If multiple signals, prefer the narrowest explicit request over the default. Do not ask a redundant routing question.

## Source tool gate
- Use actual A/V inspection tools when available; a web result is not audiovisual proof.
- If only metadata, deliver credible provisional story concepts, while calling cinematography unknown; no invented visual DNA.
- External channel tools are optional and must be checked for actual availability.

## Authorization gate
`ONE_LINK_STUDIO` and `CREATE` may prepare scripts and specifications without approval. Paid renders need an explicit authorized `provider/model/quality/duration/attempts/budget_cap` and usable tools. No permission implied from “делай” if it would newly charge money without discussed limits. Posting requires distinct explicit authorization.

## State-dependent routing
- Treat `SPECCED` as planned, not generated.
- A record cannot advance from `PILOT_SPEC` to `PILOT_GENERATED` without concrete artifact references.
- `PILOT_QC` requires inspection evidence of actual resulting audio/video and zero unresolved critical defects.
- When blocked by media/source/tool/budget, do as much free source-grounded preparatory work as possible, then state one precise blocker.

## Spoken/short-message examples
- `https://youtu.be/abc123` → `ONE_LINK_STUDIO`.
- `Вот ссылка. Мне нужен похожий визуал, но свой фильм` → `CREATE`, include the 3-idea pitch unless user already chose a story.
- `Разбери только операторскую работу` → `ANALYZE`, focused technical DNA.
- `Мне понравились A и B, смешай` → `MULTI_REF` with evidence-backed influence separation.
- `дальше` → `CONTINUE` from verified production state.
- `Клип 4 дергается` → `REPAIR` using the real clip and exact failure range.
