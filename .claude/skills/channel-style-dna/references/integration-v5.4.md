# Integration with YouTube Cinematic DNA V5.4.1

This is an *additional* skill, not an overwrite. Install sibling folders:

```
.agents/skills/
  channel-style-dna/SKILL.md
  youtube-cinematic-dna/SKILL.md
```

## Ownership boundaries
- `channel-style-dna`: identify OWN materials, lock user's channel identity, translate competitor mechanics into native design, reject brand drift, maintain cross-episode brand governance.
- `youtube-cinematic-dna`: full YouTube media access/evidence gate, technical video forensics, blocking/camera/light/motion/sound, choice of model/method, 20–40s pilot, physically grounded QC and iteration.
- Share only compact artifacts: evidence IDs/coverage; `BRAND_LOCK` / `SCENE_LOCK` / `SHOT_DELTA`; transferred reference principles; pilot film spec, media inspections and statuses.

## When both are triggered
1. Run OWN brand evidence pass once (reuse approved lock).
2. Apply cinematic DNA audit to competitor media when actual A/V accessible.
3. Interpret reference principle only through locked channel brand constraints.
4. Develop original ideas, pilot and story details.
5. QC twice: first filmcraft/cinematic and then user's brand identity + originality.
6. If visual look deviates from an approved brand but reference match is strong, **fix brand deviation** rather than congratulating on imitation.

A lone competitor URL after a brand has been locked: call brand skill then cinematic skill as needed; never replace brand by inferred competitor palette.

If no installed cinematic skill, this skill can still perform a limited evidence-labeled preliminary analysis and create production specifications; it does not claim actual generative, editing, or video-inspection tools.
