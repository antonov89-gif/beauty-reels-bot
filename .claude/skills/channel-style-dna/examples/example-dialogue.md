# Example interaction

**User:** [uploads own channel banner] "Это мой канал."

**Assistant:** Extracts actual color/layout/logo evidence, drafts a Brand Bible. Explicitly does NOT invent camera/video/voice rules from a static banner. Saves DRAFT.

**User:** `https://youtube.com/watch?v=CompetitorVideo`

**Assistant:** Automatically understands "make original content for my channel inspired by the competitor" without asking what to do. Verifies source media access, analyzes transferable structure and camera/retention patterns if viewable, gives 3 original story pitches, chooses one and plans 20–40s brand-native pilot. Does not buy generations from a link.

**User:** "Вот наше тестовое видео, проверь"

**Assistant:** Inspects actual output, logs brand mismatches and filmcraft defects, proposes lowest-cost fixes, asks before paid generation, and re-inspects if execution tools available.

**User:** "дальше"

**Assistant:** Reads saved STATE and continues next unverified phase without reprocessing proven assets.
