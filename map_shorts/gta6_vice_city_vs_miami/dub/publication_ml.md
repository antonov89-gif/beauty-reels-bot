# Multi-language package (ES, PT-BR, HI)

Files per language: `audio_<lang>.m4a` (full mix: dubbed voice + the same music and SFX, 8:26, about -13 LUFS), `gta6_vice_city_vs_miami_<lang>.srt`, script `<lang>.txt`.
Voice: the same AI voice (ElevenLabs via Lumean), each line placed on the English line's timing; long lines sped up at most x1.19 (ES), x1.29 (PT, Keys line), x1.17 (HI).

How to upload: YouTube Studio > video > Languages > Add language > Audio track: upload `audio_<lang>.m4a`; add the title/description below and the SRT as subtitles for that language.
Note: the English captions are burned into the picture, they stay visible on every track. If you want clean localized versions, the video can be re-rendered with captions in each language.
